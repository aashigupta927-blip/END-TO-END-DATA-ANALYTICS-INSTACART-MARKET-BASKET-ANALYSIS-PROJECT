# 🛒 Instacart Market Basket Analysis & Customer Segmentation

## 🚀 Project Highlight
Analyzed 3M+ Instacart orders to uncover product associations, customer behavior, and revenue-driving insights using SQL, Python, and Power BI.

**Key Outcomes:**
- Identified high-impact cross-selling opportunities using Market Basket Analysis  
- Segmented customers into actionable groups using RFM + K-Means  
- Discovered peak shopping trends to optimize operations and marketing  

---

## 📌 Business Problem
E-commerce platforms generate massive transactional data, but often lack clear insights into:
- Which products are frequently bought together  
- Who their most valuable customers are  
- When customers are most active  

This project aims to transform raw Instacart data into **actionable insights** to improve cross-selling, customer retention, and operational efficiency.

---

## 🛠️ Tools & Technologies
- **Programming:** Python (Pandas, NumPy, MLxtend, Scikit-learn)  
- **Database:** SQL (CTEs, Window Functions, NTILE)  
- **Visualization:** Power BI, Excel  
- **Techniques:**  
  - Data Cleaning & EDA  
  - Market Basket Analysis (Apriori Algorithm)  
  - Customer Segmentation (RFM + K-Means)  

---

## 🔍 Project Workflow
1. **Data Cleaning & Preparation**  
   - Processed and merged multiple datasets using Python  
   - Handled missing values and structured data for analysis  

2. **Exploratory Data Analysis (EDA)**  
   - Analyzed order trends, product demand, and customer behavior  

3. **Market Basket Analysis**  
   - Applied Apriori Algorithm to identify frequent itemsets  
   - Generated association rules using support, confidence, and lift  

4. **Customer Segmentation**  
   - Performed RFM analysis  
   - Applied K-Means clustering for customer grouping  

5. **SQL Analysis**  
   - Built structured tables  
   - Used CTEs and window functions for advanced insights  

6. **Dashboard Development**  
   - Designed interactive dashboards in Power BI  
   - Visualized product performance and customer insights  

---

## 💡 Key Business Insights
- **Bananas emerged as the highest-selling product** with strong reorder behavior, indicating high customer dependency  
- Frequently bought combinations like **Bananas & Avocado** highlight strong cross-selling opportunities  
- **Average basket size (~3 items)** suggests smaller but frequent purchases  
- Peak shopping hours observed between **10 AM – 3 PM (highest at 2 PM)**  
- **Weekends and Mondays** show highest order volume  
- Majority of users fall into **low-value customer segment**, indicating strong opportunity for conversion strategies  

---

## 📈 Business Impact
- Enabled **product bundling strategies** using association rules  
- Improved **customer targeting** through segmentation  
- Identified **peak demand hours** for operational optimization  
- Highlighted opportunities to **increase customer lifetime value (CLV)**
